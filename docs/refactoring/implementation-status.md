# 重构实施状态

## 第一阶段：纯 Java 授权核心

已建立 `sparrow-platform` 聚合入口及 security-api、rbac-core、data-policy-core 三个新模块。无旧模块运行时依赖，无兼容转发类。

实现了资源/scope 注册、角色授权、拒绝优先与资格来源；行/字段策略保留各自行条件；业务行约束只能进一步收窄。授权数据和身份均以不可变快照传入。

已执行 `mvn -o -f sparrow-platform/pom.xml test`，88 个用例全部通过。最初采用 JUnit 5.11.4，离线运行因缺少 launcher 失败；调整为本机缓存完整的 5.10.3 后成功。没有修改旧依赖版本，也没有向目录外安装依赖。

验证覆盖 81 种功能/行授权组合及相反规则顺序，并测试逐行字段隔离、拒绝优先、无授权缺省拒绝、业务追加约束、用户/群组主体、作用域不匹配、空值与非法输入。

本状态不表示整体重构完成；尚未执行部署数据库迁移或生产部署。阶段一已提交为 8046329，未推送。

## 第二阶段：JPA 查询与受控更新

新增 data-policy-jpa，通过 Specification/Criteria 编译权限表达式，权限过滤先于分页和计数；返回逐行裁剪的值映射，避免返回完整受管实体。隐含字段不能用于任意筛选/排序。增加结构化 OR/NOT/IN 与字段追加限制。

受控 patch 要求事务和 update scope，检查可写字段、旧记录/新状态、业务 guard 和版本；所有授权检查先于实体变更。当前适配器只支持显式注册的标量字段和单主键，不支持的关联/类型明确失败。

H2 真实数据库集成测试覆盖分页计数、混合行字段隔离、SQL/内存空值一致性、敏感字段过滤拒绝、范围转移拒绝、过期版本、业务冻结与事务回滚。完整 reactor 共 97 个测试通过（88 核心 + 9 JPA）。H2 不替代生产数据库方言验收。

## 第三阶段：本地身份与可选装配

新增 identity-api、identity-local、identity-local-spring-boot-starter。默认使用 Spring Security DaoAuthenticationProvider/PasswordEncoder 和 JPA 账号存储；主体稳定 ID 与用户名分离，管理操作要求宿主提供管理授权 guard，密码专用命令与资料修改分离。

已验证真实数据库登录、密码哈希、启停、重置、旧会话失效、命名空间隔离、版本冲突、provider 缺失/重复；HTTP 测试覆盖会话登录和凭据重置后的 401。外部 provider 模式不装配本地数据库/登录链，无实现时启动失败。

完整 reactor 108 个测试通过（新增 8 个本地身份、3 个 Spring/HTTP 装配测试）。角色 provider、管理 REST/UI、登录失败限制、生产迁移脚本和外部认证桥接仍在后续阶段，不能仅凭这些测试视为完整身份交付。

## 第四阶段：角色、策略发布和群组持久化

新增 rbac-jpa、group-core/jpa。角色和角色分配通过 Criteria 读写，当前数据库关系决定有效角色，不信任会话的旧角色快照；用户/群组授予、角色停用、显式拒绝和 scope 来源分别验证。角色管理 SPI 可由项目替换；外部角色管理完整装配仍待后续。

数据策略增加草稿/发布/撤销、版本冲突、命名空间、显式 JSON AST 编解码及发布时 JPA 字段/类型校验。无发布规则时无数据许可。群组采用不可变图与命名空间事务锁，支持成员/嵌套/停用、环检测和全量变更前后委派检查。

完整 reactor 126 个测试通过：新增 6 个角色、5 个策略生命周期、4 个群组图、3 个群组数据库用例。群组当前采用有容量上限的命名空间快照，尚未进行大规模组织性能评估；管理 guard 必须由宿主接入真实授权，测试中的允许 guard 不是生产默认值。
